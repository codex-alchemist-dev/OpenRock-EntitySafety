# OpenRock-EntitySafety

Safe wrappers for three real, previously-reproduced Bedrock timing/bounds traps: early-execution-unsafe world calls, dimension-change event location drift, and per-dimension Y-bounds clamping.

Part of the [OpenRock](https://github.com/codex-alchemist-dev/OpenRock) Minecraft Bedrock mod-packaging ecosystem - a Codex Alchemist project, under Fireball Everything. Consumed as a real git submodule at `libs/entity-safety` in the main OpenRock repo, and directly `npm require`/`import`-able (real top-level CommonJS exports, esbuild-CJS/ESM-interop-compatible) by any mod's own build-time kernel registration or real in-game script.
